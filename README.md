# E-commerce AI Chatbot for Shopify Stores

A lightweight AI chatbot that answers common e-commerce questions like shipping, returns, COD, product availability.

Perfect for Shopify / WooCommerce stores to reduce support time by 70%.

### Features
- ✅ Answers FAQs (Shipping, Return, COD, Payment)
- ✅ Product search from FAQ JSON
- ✅ Easy to integrate with Shopify via Custom Liquid
- ✅ Can be connected to OpenAI API for AI replies

### How it works
1. Customer asks: "COD available?"
2. Bot checks `data/faqs.json`
3. Returns instant answer

### Demo
python bot.py

### For Store Owners
You can customize `data/faqs.json` with your own store FAQs.
